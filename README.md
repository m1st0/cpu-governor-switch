## 🛠️ Usage

1. Clone the repo:

    ```bash
    git clone --recurse-submodules https://github.com/yourusername/cpu_governor_switch.git cpu_governor_switch
    cd cpu_governor_switch
    ```

    If the project was already cloned without its submodules:

    ```
    git submodule update --init --recursive
    ```

2. Make executable:

    ```bash
    chmod +x *.sh
    ```

3. Run (may require sudo):

    ```bash
    performance_switch_cpu.sh

    ```
